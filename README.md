# Python Loop Visualizer

Web interaktif berbahasa Indonesia untuk melihat alur `for`, `while`, dan nested loop Python, satu langkah logis setiap kali. Buka `index.html` langsung di browser. Tidak perlu instalasi, server, atau koneksi internet.

Pilih tab dan atur input di bagian atas kartu. Kontrol berada tepat di bawah input. Area utama menampilkan tiga bagian: kode Python yang disorot, nilai saat ini, dan satu hasil `print()` terbaru. Hasil terbaru ditandai saat baris `print()` dijalankan. Pada nested loop, nilai `i` dan `j` tampil di dua area terpisah. Untuk string, ␠ berarti spasi, ↵ berarti baris baru, dan ⇥ berarti tab.

Gunakan **Langkah Berikutnya** untuk satu operasi, **Mulai / Lanjutkan** untuk menjalankan otomatis, **Jeda** untuk menahan posisi, dan **Reset** untuk kembali ke awal. Simulasi dibatasi hingga 60 nilai per sumber, 120 pelaksanaan `print()`, dan 500 langkah. Input teks maksimal 2.000 karakter. Jika batas tercapai, status menunjukkan **Batas simulasi tercapai**.

JavaScript menyimulasikan kode yang tampil tanpa interpreter Python.
